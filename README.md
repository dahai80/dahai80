## 🧠 Why Fusion?

| ⚡ One Core | 🖥 Nine Surfaces | 🔋 100% Local |
|---|---|---|
| `fusion-mlx` is a single OpenAI-compatible inference engine (localhost:11434) that drives the entire ecosystem. | Desktop, CLI, web, coding, docs, science, finance, health, education — all built on the same core. | Models, memory, and knowledge stay on-device or intranet-only. No outbound traffic except 127.0.0.1. |

|---|---|---|

| **Entry** | `fusion-cli` | Rust single-binary `fusion` command |
